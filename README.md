# ShopEase – E-Commerce Website

ShopEase is a full-stack e-commerce website designed to provide users with a simple, responsive, and user-friendly online shopping experience.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** Python, Django
* **Database:** MongoDB

## ✨ Features

* Responsive and modern user interface
* User registration and login
* Product browsing and product details
* Shopping cart functionality
* Dynamic product management
* MongoDB database integration
* Django-based backend functionality

## 📌 Project Overview

ShopEase allows users to explore available products, view product information, add items to their shopping cart, and manage their shopping experience through an interactive web interface. Django handles the backend logic, user authentication, and communication between the frontend and database, while MongoDB is used to store and manage application data.

Bootstrap was used to make the website responsive across different screen sizes, while JavaScript provides interactive functionality on the frontend.

## 🎯 Objective

The main objective of this project was to develop a practical full-stack e-commerce application and gain hands-on experience in **frontend development, backend programming, database management, user authentication, and frontend-backend integration**.

This project demonstrates the implementation of a complete web application using modern web development technologies.
